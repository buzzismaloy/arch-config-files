# Hotkeys used in current Arch Linux configuration

## How to open something:

* **Open the terminal** - `super + enter`
* **Open file manager** - `super + e`
* **Open the application menu** - `super + w`
* **Open firefox** - `super + f`
* **Open obsidian** - `super + b`
* **Open visual studio code** - `super + c`
* **Open pycharm** - `super + j`
* **Open zed editor** - `super + z`
* **Open mousepad text editor** - `super + t`

## System management

* **Close active window** - `super + q`
* **Lock the screen** - `super + l`
* **Toggle floating** - `super + k`
* **Toggle split** - `super + o`
* **Toggle pseudo** - `super + p`
* **Open clipboard within wofi** - `super + v`
* **Clear clipboard history** - `super + shift + v`
* **Switch on/off waybar** - `super + u`
* **Set random wallpaper** - `super + r`

## Taking screenshots

* **Take a screenshot** - `print`
* **Take a screenshot of an active window** - `super + print`
* **Take a screenshot of the desktop** - `super + shift + print`

## Window management

* **Switch to another workspace** - `super + [0-9]`
* **Move focus within workspace** - `super + [←, ↑, →, ↓]`
* **Move window within workspace** - `super + shift + [←, ↑, →, ↓]`
* **Move active window to another workspace silently** - `super + shift + [0-9]`
* **Scroll through existing workspaces** - `super + mouse-wheel-up/mouse-wheel-down`

***Hotkeys that manage volume, brightness and playerctl are in `~/.config/hypr/hyprland.conf`.***
