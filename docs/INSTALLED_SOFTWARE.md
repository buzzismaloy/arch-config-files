# Arch Linux Installed System Software

## 1. System Components

### Graphics System

- `wayland` - Wayland display server protocol
- `xorg-server` — Xorg display server
- `xorg-xinit` — Xorg initialization
- `qt5-wayland` - Qt5 Wayland support
- `qt6-wayland` - Qt6 Wayland support
- `hyprland` - Dynamic tiling Wayland compositor
- `xdg-desktop-portal-hyprland` - XDG Desktop Portal for Hyprland

### Display Manager

- `sddm` - Login manager

### Window Manager

- `waybar` - Highly customizable Wayland status bar
- `dunst` — Notification daemon
- `wlogout` - Logout menu for Wayland
- `nwg-look` - GTK appearance settings
- `polkit-kde-agent` — PolicyKit authentication agent

### Clipboard & Screenshots

- `cliphist` — Clipboard manager
- `hyprshot` — Screenshot utility for Hyprland

### Audio System

- `pipewire` - Modern audio server
- `pipewire-pulse` - PulseAudio replacement
- `pipewire-alsa` - ALSA integration
- `pipewire-jack` - JACK integration
- `wireplumber` - Session manager for PipeWire
- `pavucontrol` - Audio mixer
- `libpulse` — PulseAudio client libraries
- `gst-plugin-pipewire` — GStreamer PipeWire plugin

### Network System

- `networkmanager` - Network management
- `network-manager-applet` - Network GUI
- `iwd` - WiFi daemon
- `openssh` - SSH server/client
- `net-tools` - Classic network utilities (netstat, ifconfig)
- `inetutils` — Network utilities
- `rsync` — File synchronization
- `wireless_tools` — Wireless utilities
- `gnu-netcat` — Networking tool [AUR]

### Bluetooth

- `blueman` - Bluetooth GUI manager
